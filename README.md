# Vantage Voice (SonicMind S2S) — Realtime Speech-to-Speech Conversational AI

**🌐 Live app: [https://vantage-voice.89-117-74-224.sslip.io](https://vantage-voice.89-117-74-224.sslip.io)** — installable as a PWA (open in Chrome/Safari and use "Add to Home Screen").

Vantage Voice is a **Speech-to-Speech (S2S)** real-time conversational AI application built with **React**, **TypeScript**, **Tailwind CSS**, and **Express**, genuinely wired into the [Vantage](https://omokoda.duckdns.org) agent platform rather than a standalone demo. It runs **two real voice engines** depending on which persona/backend is active — see [Architecture](#-architecture-diagram--overview) below.

It enables fluid, low-latency voice conversations where users speak into their microphone and receive natural spoken responses, with **barge-in interruptions**, **Voice Activity Detection (VAD)**, **custom personas**, **live speech-to-speech translation**, and **multimodal vision/screen sharing**.

## 🔌 Real Integrations (not simulated)

- **Vantage MCP tool access**: connects to Vantage's live MCP server and discovers its real tool catalog (trading, wallet, buzz/social, jobs) at startup; the model calls them for real via `tool_search_retrieval` → `mcp_server_client`, not fabricated responses.
- **Real external agent brains**: selecting **Hermes** (Hostinger), **Hermes (Contabo)**, or **OpenClaw** in Settings routes your speech to that agent's real, separately-hosted cognition endpoint — the reply you hear is genuinely generated by that agent, not the voice model improvising. The Contabo Hermes persona is *sessionful*: each connection gets a stable `X-Hermes-Session-Key`, so it's a real continuous agent conversation (memory, tool calls persist turn to turn) via its own OpenAI-compatible gateway (`callHermesGatewaySession`), not a stateless one-shot relay. The Vantage `/api/copilot/chat` relay is kept as the automatic fallback if the gateway is unset or unreachable.
- **Two real voice engines, chosen automatically per persona** — see the architecture diagram below for when each is used: **Gemini Live** (native speech-to-speech) for the default persona, and a **cascade pipeline** (server VAD → Groq Whisper STT → agent bridge → streaming ElevenLabs TTS, with barge-in) for the Hermes (Contabo) persona and as an automatic fallback whenever no Gemini key is configured.
- **Gemini API key round-robin pool**: set `GEMINI_API_KEYS` (comma-separated) to spread sessions across multiple keys, with automatic cooldown/retry on a rate-limited key.
- **Owner-gated agent self-control**: once unlocked with a spoken PIN, the agent can manage this app's own API keys, live app settings, and a real persistent memory vault — every privileged/destructive action is enforced server-side (PIN check + explicit confirmation step, shared lockout budget across all surfaces), not just prompted. The same tools are also exposed as a real MCP server (`/mcp/voice-owner`) so an *external* agent brain (e.g. the Contabo Hermes gateway session) can call them too, not just the in-process Gemini function-calling path.
- **Money-moving tools are gated separately and cannot be relaxed by the owner unlock alone**: Vantage tools that spend or sign are held behind their own explicit confirmation regardless of PIN state; read-only tools are not gated, so the distinction stays meaningful.
- **Conversations persist to the shared Vantage memory vault**, not just browser `localStorage` — each turn is offloaded via a scoped, ingest-only connector token (`VVAULT_CONNECTOR_KEY`) that never holds the real agent key.
- **Installable PWA**: real manifest, service worker, and app icons — works as a home-screen app on mobile and desktop.
- **Real OAuth connectors** (Composio-backed): Gmail, GitHub, Outlook, Discord, Slack, GitLab, Notion, and Dropbox connect via genuine OAuth redirect + polling for real Composio connection status — no fabricated "connected" state. The Composio Tool Router session (used by the Contabo Hermes gateway) is not static — it's re-minted automatically (`scripts/composio-refresh.mjs`, on boot + a 6h systemd timer) since Composio issues a fresh URL/key on every session creation.

```

 │  │ AudioRecorder   │ │ AudioPlayer  │ │  Animated    │  │
 │  │ (16kHz PCM Mic) │ │ (24kHz PCM)  │ │ Visualizer   │  │
 │  └────────┬────────┘ └──────▲───────┘ └──────────────┘  │
 └───────────┼─────────────────┼───────────────────────────┘
             │ WebSocket Audio │ Audio & Transcripts
             ▼                 │
 ┌─────────────────────────────┴───────────────────────────┐
 │                  Express + Node.js Server                │
 │  • Realtime WebSocket Server (/api/live-s2s)              │
 │  • Function Calling / Tool Execution + MCP clients         │
 │  • /mcp/voice-owner (PIN-gated owner-control MCP server)  │
 └───┬──────────────────────────────────────────────┬──────┘
     │ backend = native / hermes / open_claw          │ backend = hermes_contabo
     │ (or any backend, if no Gemini key configured)   │ (default engine for this persona)
     ▼                                                  ▼
 ┌─────────────────────────────┐          ┌──────────────────────────────────────┐
 │  Google Gemini Live API      │          │  Cascade Pipeline (src/lib/cascade/) │
 │  • Native speech in/out       │          │  Server VAD → Groq Whisper STT →     │
 │  • Barge-in via Live events   │          │  Hermes gateway (sessionful) →       │
 └─────────────────────────────┘          │  Sentence chunker → streaming        │
                                            │  ElevenLabs TTS, with barge-in       │
                                            └──────────────────────────────────────┘
```

### Why two voice engines?
- **Gemini Live** (native speech-to-speech) is the default for the `native`/`hermes`/`open_claw` personas: sub-500ms latency, natural vocal inflection, native barge-in — no reason to cascade when a single live session already does the job.
- **Cascade** (`src/lib/cascade/engine.ts`) is the default for the **Hermes (Contabo)** persona, and the automatic fallback for any persona when no Gemini API key is configured. It exists because that persona's real value is the sessionful Hermes agent loop (tools, memory, multi-turn reasoning) — Gemini Live can't be that agent's brain, so voice I/O is cascaded around a real STT (Groq Whisper) → agent call → streaming TTS (ElevenLabs) pipeline instead, with its own barge-in via `AbortController`.

## ✨ Features

- **Bidirectional Audio Streaming**: Continuous 16kHz PCM input capture and gapless 24kHz PCM output playback.
- **Voice Activity Detection (VAD)**: Real-time volume RMS calculation with customizable sensitivity thresholds and automatic silence detection.
- **Barge-in / Interruption Support**: User can interrupt AI speech output at any point; playback instantly stops and listening resumes.
- **Custom System Personas**:
  - Sonic Assistant
  - English Language Coach
  - Senior Tech Mentor
  - Captain Blackbeard (Sarcastic Pirate)
  - Zen Mindfulness Guide
  - Live Polyglot Translator
  - Custom user prompt instructions
- **Prebuilt AI Voices**: Zephyr, Puck, Charon, Kore, Fenrir, Aoede, Calliope, Nova, Ursa.
- **Live Speech-to-Speech Translation Mode**: Translate spoken input directly into 10+ international languages using `gemini-3.5-live-translate-preview`.
- **Function Calling / Tools**: Real-time tools for weather lookup, time checking, web search, and math calculations.
- **Live Transcript Timeline**: Real-time auto-scrolling turn history with copy & text export.
- **Multimodal Camera & Screen Input**: Stream 1 FPS snapshot frames to the AI so it can see what you see.
- **Performance & Latency Telemetry**: Live metrics gauge time-to-first-audio and packet counts.

## 🚀 Local Development Setup

### Prerequisites
- Node.js (v18+ or v20+)
- npm or pnpm
- Google Gemini API Key (`GEMINI_API_KEY`)

### 1. Environment Configuration
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Set your Gemini API key in `.env` (or `GEMINI_API_KEYS` as a comma-separated list for round-robin pooling):
```env
GEMINI_API_KEY="your-gemini-api-key-here"
```

Other real integrations are optional but unlock more of the app once set — see `.env.example` for the full list: `VANTAGE_AGENT_KEY`/`VANTAGE_MCP_URL` (Vantage MCP tool access), `HERMES_AGENT_KEY`/`HERMES_CONTABO_AGENT_KEY`/`OPENCLAW_AGENT_KEY` (real external agent bridges), `HERMES_CONTABO_GATEWAY_URL`/`HERMES_CONTABO_GATEWAY_KEY` (the sessionful Hermes gateway used by the cascade engine), and `OWNER_VOICE_PIN` (required to unlock the agent's own key/settings/memory management tools during a voice session).

The cascade engine's own provider keys (Groq STT, ElevenLabs TTS) are deliberately kept **out** of `.env` and read from a separate `~/.vv-cascade-keys.env` (mode `0600`) instead — see `src/lib/cascade/keys.ts`. This keeps voice-provider credentials off the same file the owner-control MCP tools can read/write.

### 2. Install Dependencies & Run
```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.

## 📦 Deployment Instructions

The live instance runs as a `systemd` service (`npm run build && node dist/server.cjs`) behind [Caddy](https://caddyserver.com/) for automatic HTTPS — real Let's Encrypt cert, no manual renewal, required for the app to be installable as a PWA. A minimal `Caddyfile`:
```
your-domain.example.com {
    reverse_proxy localhost:3000
    encode gzip
}
```

### Docker / Cloud Run
```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

EXPOSE 3000
ENV NODE_ENV=production
CMD ["npm", "start"]
```

Build and run container:
```bash
docker build -t sonicmind-s2s .
docker run -p 3000:3000 -e GEMINI_API_KEY="your-key" sonicmind-s2s
```

## ⏱️ Latency Optimization & Production Hardening Notes

1. **Jitter Buffer Management**: In `AudioPlayer.ts`, incoming PCM audio chunks are scheduled sequentially using precise `AudioContext` timeline offsets (`nextStartTime`), preventing audio crackle or gaps under fluctuating network jitter.
2. **Downsampling & Quantization**: Mic input is resampled directly in browser to 16,000Hz mono 16-bit PCM before base64 encoding to minimize bandwidth.
3. **Graceful Reconnection**: WebSocket heartbeat (`ping`/`pong`) ensures connection health and auto-reconnects on temporary network drops.
